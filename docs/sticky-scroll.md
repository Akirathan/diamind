# Sticky scroll

- Inspired from VSCode
- By default, 5 items are visible in sticky scroll. Configurable.
- When scrolling down, and the parent node of the top most visible node is not visible anymore, it will be displayed in the sticky scroll.
- Hovering over an item in the sticky scroll highlights it (grey background, and pointer cursor).
- clicking on an item from sticky scroll scrolls up to the item.
